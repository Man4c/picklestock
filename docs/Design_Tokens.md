# Design Tokens (`Design_Tokens.md`)

Document ini berisi spesifikasi Design Tokens berdasarkan analisis visual dari mockup aplikasi e-commerce mobile (**AJAIRA**).

---

## 1. Theme
* **Primary Style:** Light Mode / Modern Minimalist / Clean UI
* **Vibe:** Sleek, high-contrast, modern e-commerce storefront with subtle floating navigation elements.

---

## 2. Color Palette (Hex)

### Core Colors
* **Primary Background:** `#FFFFFF` (Pure White)
* **Secondary / Card Fill:** `#F5F6F8` (Light Grey Off-White)
* **Search / Input Fill:** `#F8F9FA` (Soft Neutral White)
* **Primary Text & High Contrast:** `#111111` (Deep Black / Dark Charcoal)
* **Secondary Text:** `#6B7280` (Muted Medium Grey)
* **Muted / Subtitle Text:** `#9CA3AF` (Light Cool Grey)

### Accent & Branding
* **Brand Card Fills (Dark):** `#000000` / `#18181B` (Rich Dark Slate)
* **Action Buttons ("Buy Now", "Add to cart"):** `#111111` (Dark Solid Button)
* **Presentation Canvas (Background):** `#D9FE83` to `#3EA8B3` (Lime to Teal Gradient)

---

## 3. Typography

* **Font Family:** Modern Sans-Serif (e.g., *Inter*, *SF Pro Display*, or *Plus Jakarta Sans*)

| Element | Style / Weight | Size (Approx.) | Tracking / Letter Spacing |
| :--- | :--- | :--- | :--- |
| **App Title / Logo** | Custom Geometric Bold | ~20px | Condensed / Bold Display |
| **Section Eyebrow** | Uppercase Bold | 10px - 11px | +1.5px (Wide tracking) |
| **Section Title** | Extra Bold / Heavy | 16px - 18px | Normal |
| **Product Title** | Semi-Bold / Medium | 13px - 14px | Normal |
| **Price Tag** | Bold | 14px - 16px | Normal |
| **Body / Meta Text** | Regular | 11px - 12px | Normal |
| **Button Text** | Medium / Semi-Bold | 12px - 13px | Normal |

---

## 4. Spacing & Padding

* **Screen Outer Margin:** `16px` - `20px`
* **Card Inner Padding:** `12px` - `16px`
* **Section Gap (Vertical):** `20px` - `24px`
* **Grid Item Gap (Horizontal):** `12px`
* **Search Bar Padding:** `12px 16px`
* **Floating Bottom Nav Bar Padding:** `12px 20px`

---

## 5. Border Radius & Shadows

### Border Radius
* **Search Bar:** `14px`
* **Brand / Category Cards:** `14px`
* **Featured Product Card:** `16px`
* **Product Card Thumbnails:** `16px`
* **Buttons:** `8px` (Semi-rounded pill)
* **Bottom Navigation Bar:** `24px` (Rounded Floating Pill)

### Shadows & Borders
* **Card Border:** `1px solid #E5E7EB` (Subtle hair-line stroke for featured card)
* **Elevation / Shadow:** 
  * Soft elevation for floating bottom navigation: `0px 10px 25px rgba(0, 0, 0, 0.08)`
  * Subtle card shadow: `0px 2px 8px rgba(0, 0, 0, 0.04)`
